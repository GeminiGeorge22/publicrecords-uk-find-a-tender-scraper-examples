## Synchronen Lauf starten

Setze `APIFY_TOKEN` auf dein eigenes Apify-Token. Nicht ins Repository committen.

```bash
export APIFY_TOKEN=YOUR_TOKEN
python3 examples/python/run.py
# node examples/javascript/run.js
# bash examples/curl/run.sh
```

Beispiele in Python, JavaScript und curl liegen unter `examples/`. Autor: Public Records. Lizenz: MIT. Dieses Repository enthält keine GitHub Actions.
